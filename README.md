# MURL Chess

Machine Learning, Chess and Mathematics

This project explores chess algorithms and machine learning methods as part of the MURL research project.

## Current Work

- Minimax
- Monte Carlo Tree Search (MCTS)

## Files

- `minimax.py` - Minimax chess search algorithm
- `mcts.py` - Monte Carlo Tree Search implementation
- `results.txt` - Minimax results
- `results1.txt` - MCTS results

## Future Work

- Reinforcement learning
- Neural networks

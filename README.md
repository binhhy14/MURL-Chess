# MURL Chess

## Machine Learning, Chess and Mathematics

This repository contains my work for the MURL research project on
chess algorithms, machine learning, and mathematics.

The project currently focuses on chess search algorithms and will
later explore neural networks and reinforcement learning.

## Project Goals

- Implement Minimax for chess
- Implement Monte Carlo Tree Search (MCTS)
- Test both methods on chess positions
- Measure execution time and search behavior
- Compare Minimax and MCTS
- Study neural networks and reinforcement learning
- Develop the work toward an expository paper and final poster
